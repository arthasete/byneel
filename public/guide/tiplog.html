Premiers Pas

Installation

TipLog est disponible sur iOS (App Store) et Android (Google Play). Téléchargez l'app gratuite et ouvrez-la pour commencer.

Permissions Nécessaires

À la première utilisation, TipLog vous demande les permissions suivantes (optionnelles) :

  • Localisation (GPS) - Pour détecter automatiquement votre pays et devise
  • Appareil photo - Si vous souhaitez activer le mode scanner (Premium)

Vous pouvez refuser ces permissions et sélectionner manuellement votre pays dans les paramètres.

Configuration Initiale

Sélectionner Votre Pays

1Accédez aux Paramètres

Appuyez sur l'icône engrenage (paramètres) en haut à droite.

2Choisissez Votre Région

Sélectionnez votre pays dans la liste. Cela change automatiquement la devise et les taux de pourboire standards.

3Confirmer

La devise s'affiche immédiatement dans l'écran principal. Vous pouvez revenir modifier ce paramètre à tout moment.

Personnaliser les Pourcentages

Dans les paramètres, vous pouvez définir vos propres pourcentages de pourboire (par défaut : 15%, 18%, 20%). Appuyez sur le pourcentage pour le modifier.

Utilisation Quotidienne

Calculer un Pourboire

1Ouvrir TipLog

L'écran principal affiche le clavier de calcul.

2Entrer le Montant

Appuyez sur les chiffres pour saisir le montant du repas ou du service. Le clavier affiche les caractères pour une saisie facile.

3Sélectionner le Pourcentage

Appuyez sur l'un de vos pourcentages (15%, 18%, 20% ou personnalisé). TipLog calcule et affiche immédiatement le montant du pourboire et le total.

4Enregistrer (Optionnel)

Appuyez sur "Enregistrer" pour ajouter cette dépense à votre historique. Vous pouvez aussi ajouter une note (restaurant, événement, etc.).

Conseil : Vous n'êtes pas obligé d'enregistrer chaque calcul. Le bouton "Enregistrer" est optionnel si vous voulez juste calculer rapidement.

Gérer Votre Historique

Consulter l'Historique

L'onglet "Historique" affiche tous vos calculs enregistrés avec :

  • Date et heure
  • Montant du repas et pourboire
  • Notes personnelles
  • Statistiques (total, moyenne)

Modifier une Entrée

Appuyez sur une entrée pour l'éditer. Vous pouvez modifier le montant, le pourcentage ou les notes.

Supprimer des Entrées

Glissez-déposez sur une entrée vers la gauche, puis appuyez sur la corbeille. Vous pouvez aussi supprimer tout l'historique depuis les paramètres.

Exporter Vos Données

Créer un Rapport

Dans l'onglet "Historique", appuyez sur l'icône "Partager" (carré avec flèche) pour exporter vos données.

Formats Disponibles

  • PDF - Avec graphiques et statistiques. Parfait pour imprimer.
  • CSV - Format tableur pour Excel ou Google Sheets. Utile pour des analyses approfondies.

Partager ou Sauvegarder

Après l'export, vous pouvez :

  • Envoyer par email
  • Sauvegarder dans le cloud (iCloud, Google Drive)
  • Imprimer directement
  • Partager via Messages ou autres apps

Fonctionnalités Avancées

Calcul Arrondi (Mode "Round")

Activez cette option dans les paramètres pour arrondir automatiquement le total à un montant entier facile à payer (par exemple, €35 au lieu de €34,73).

Historique Statistiques

L'écran "Historique" affiche des statistiques utiles :

  • Nombre total de pourboires donnés
  • Montant moyen du pourboire
  • Pourcentage moyen appliqué

Convertisseur de Devise

Si vous voyagez, vous pouvez changer de devise temporairement sans modifier votre région. Allez dans les paramètres et sélectionnez une devise différente.

Passer à TipLog Pro

Avantages Premium

TipLog Pro déverrouille :
  • Aucune publicité
  • Historique illimité sans suppression
  • Exportation personnalisée avancée
  • Thèmes et personnalisations premium
  • Mode "Round" intelligent

Souscrire à Pro

Appuyez sur "Débloquer Pro" dans les paramètres ou dans l'app. Un essai gratuit est généralement disponible avant d'être facturé.

Gérer Votre Abonnement

Vous pouvez gérer, modifier ou annuler votre abonnement Pro via :

  • iOS - Paramètres > App Store > Compte > Abonnements
  • Android - Google Play > Compte > Abonnements > TipLog

Conseils et Astuces

Calculs Rapides

Vous n'avez pas besoin d'enregistrer chaque calcul. Utilisez TipLog comme une calculatrice pour des calculs rapides au restaurant.

Notes Personnalisées

Lorsque vous enregistrez un pourboire, ajoutez une note avec le nom du restaurant ou l'événement. Cela rend votre historique plus significatif.

Synchronisation Manuelle

Vos données restent locales sur votre appareil. Pour accéder à votre historique sur un autre téléphone, exportez vos données en CSV et importez-les.

Sauvegardes Régulières

Nous recommandons d'exporter votre historique régulièrement en PDF ou CSV pour sauvegarder vos données.

Dépannage

L'App Plante au Démarrage

Essayez de supprimer et de réinstaller l'app. Vos données historiques peuvent être restaurées depuis une sauvegarde CSV.

GPS ne Fonctionne pas

Vérifiez que vous avez autorisé la permission de localisation pour TipLog dans les paramètres de votre téléphone. Vous pouvez aussi sélectionner manuellement votre pays.

L'Export Échoue

Assurez-vous d'avoir suffisamment d'espace de stockage. Essayez d'exporter vers un format différent (PDF ou CSV).
